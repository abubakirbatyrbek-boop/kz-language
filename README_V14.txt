V14：零基础造句与口语课模块闯关

更新 speaking.js + speaking-course.html 即可。

功能：
1. 完成一个模块全部小课后，出现“模块测试”。
2. 测试答对 >= 70% 才解锁下一模块。
3. 下一模块未解锁时显示锁定；不能跳过去学习。
4. 模块内也按小课顺序推进；前一课完成后才能进入下一课。
5. 顶部完成进度会实时更新，例如 1/70、8/70。
6. 模块测试结果保存到 localStorage，并在登录状态下写入 Supabase test_results。
7. 登录后会从 Supabase 恢复已有课程进度和模块测试通过状态。
8. 哈萨克语只播放哈萨克语；俄语只播放俄语。

无需修改 supabase-config.js，也无需重新执行数据库 SQL。
