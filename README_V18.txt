V18 零基础造句与口语课程 UI 修正版

本版保留现有 speaking.js 的全部课程内容和原有功能，仅新增可见的“模块闯关”区域：
1. 每个模块必须完成全部小课。
2. 每个模块都有独立模块考试。
3. 考试答对 >= 70% 才通过并进入下一模块。
4. 第2模块开始必须注册/登录。
5. 登录后的学习进度与考试成绩继续使用现有逻辑保存。
6. 原来的课程模块、小课、记忆提示、发音和自己说内容不删除。

- speaking-course.html 覆盖原文件
- speaking-v18.js 新增
- speaking-v18.css 新增
无需修改 speaking.js 和 Supabase 配置。
