# 中亚语言通 V6

V5 改为“初学者优先”的闯关式路线：

字母与发音 → 听音认字 → 拼读与基础词 → 问候 → 基本句型 → 造句 → 真实场景

### 主要变化
- Unit 1 从字母与发音开始，不再要求零基础用户一上来做选择题。
- 认识发音小课加入“听示范”按钮。
- 继续保留选择、听力、翻译、组句、造句和单元考试。
- 单元考试需要完成所有小课，达到 80% 才能解锁下一单元。
- 使用 v5_progress 本地学习记录，避免 V4 旧进度误解锁。
- 已准备 supabase-v5-schema.sql，用于云端保存登录用户的学习进度和考试结果。

> 语音目前使用浏览器 SpeechSynthesis；不同浏览器可用的哈萨克语语音可能不同。后续可以替换成真人录音。


## V6 本次新增：注册门槛与云端进度

- 游客可以免费体验第 1–3 单元。
- 第 4 单元及以后需要注册/登录。
- 登录后学习进度、单元通过状态和考试成绩按用户保存到 Supabase。
- 游客在当前设备的进度会在第一次登录时尝试迁移到新账号。
- `supabase-config.js` 不要用本压缩包中的占位配置覆盖你 GitHub 里已经填写好的正式配置。
- 如果你的 Supabase 还没有创建 `learning_progress` 和 `test_results`，运行 `supabase-v6-schema.sql` 一次。
