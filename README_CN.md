# 中亚语言通 V0 原型

这是一个可以直接在浏览器打开的公开网站原型，定位是：给中国人在哈萨克斯坦生活、工作、商务沟通使用的哈萨克语 + 俄语学习平台。

## 当前已经实现
- 首页品牌与定位
- 哈萨克语 / 俄语双语展示
- 课程卡片
- 生活 / 物流 / 工厂 / 铁路 / 海关 / 商务场景入口
- 学习卡片切换
- 浏览器语音朗读
- 本机 localStorage 学习进度
- 手机端自适应

## 目前没有
- 用户注册登录
- 云端数据库
- AI 对话
- 在线支付
- 后台课程管理

这些适合在验证用户需求以后加入。

## 本地打开
最简单的方法：直接双击 `index.html`。

也可以用 VS Code / Cursor 的 Live Server 打开。

## 下一步上线公网
建议第二阶段改造成 Next.js + Supabase，然后部署到 Vercel，并绑定自己的域名。
